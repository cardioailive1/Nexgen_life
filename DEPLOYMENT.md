## Compliance Coverage

| Standard | Implementation |
|---|---|
| **SOC2 Type II** | Audit logs (CC7.2), rate limiting (CC6.1), encryption at rest + transit, RBAC, session management |
| **GDPR / UK GDPR** | Data export (Art.20), right to erasure (Art.17), consent recording, privacy policy versioning, data retention policy |
| **ISO 27001** | Access controls, audit trail, secure coding (input validation, helmet, CORS), incident logging |
| **OAuth2** | Google OAuth2 via Passport.js (openid-client compatible), PKCE-ready |
| **HIPAA-adjacent** | Audit logs, encryption, access controls, minimum necessary data collection |
| **PCI-DSS** | No card data stored — Stripe handles all PCI scope |

## Step 1 — Deploy to Render.com

### Option A: One-click Blueprint
1. Push this folder to a GitHub/GitLab repo
2. Go to https://dashboard.render.com → New → Blueprint
3. Connect your repo — Render detects `render.yaml` automatically
4. Click **Apply** — creates the web service + PostgreSQL database

### Option B: Manual
1. Go to https://dashboard.render.com → New → Web Service
2. Connect your repo
3. Set:
   - **Build Command:** `npm install && npx prisma generate && npx prisma migrate deploy`
   - **Start Command:** `node src/server.js`
   - **Health Check Path:** `/health`

---

## Step 2 — Set Environment Variables

In Render dashboard → Your service → Environment → Add the following (values from `.env.example`):

**Required:**
```
ANTHROPIC_API_KEY=sk-ant-...
STRIPE_SECRET_KEY=sk_live_...
STRIPE_WEBHOOK_SECRET=whsec_...
STRIPE_STARTER_PRICE_ID=price_...
STRIPE_PROFESSIONAL_PRICE_ID=price_...
GOOGLE_CLIENT_ID=...
GOOGLE_CLIENT_SECRET=...
SMTP_PASS=re_...  (Resend API key)
```

**Auto-generated by Render Blueprint (no action needed):**
- `DATABASE_URL`
- `JWT_SECRET`
- `JWT_REFRESH_SECRET`
- `COOKIE_SECRET`
- `ENCRYPTION_KEY`

---

## Step 3 — Configure Google OAuth2

1. Go to https://console.cloud.google.com → APIs & Services → Credentials
2. Create OAuth 2.0 Client ID → Web application
3. Authorised redirect URIs: `https://nexgenlife.onrender.com/auth/google/callback`
4. Copy Client ID and Secret → add to Render env vars

---

## Step 4 — Configure Stripe Webhooks

1. Go to https://dashboard.stripe.com → Developers → Webhooks → Add endpoint
2. Endpoint URL: `https://nexgenlife.onrender.com/webhooks/stripe`
3. Events to listen for:
   - `checkout.session.completed`
   - `invoice.payment_succeeded`
   - `invoice.payment_failed`
   - `customer.subscription.deleted`
   - `customer.subscription.updated`
4. Copy Signing Secret → set as `STRIPE_WEBHOOK_SECRET`

---

## Step 5 — Create Stripe Price IDs

In Stripe dashboard → Product catalog:
- **NexGenLife Starter** → $99.00/month recurring → copy Price ID → `STRIPE_STARTER_PRICE_ID`
- **NexGenLife Professional** → $499.00/month recurring → copy Price ID → `STRIPE_PROFESSIONAL_PRICE_ID`
